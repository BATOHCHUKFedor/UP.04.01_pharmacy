# Аптечный каталог

Учебное приложение на Flutter Web. Пять разделов: препараты, поставщики,
производители, категории и лицензии поставщиков.

## Запуск

```shell
flutter pub get
flutter run -d chrome --web-port=5000
```

Используйте один и тот же адрес и порт при повторном запуске: браузер хранит
данные отдельно для каждого адреса. В приватном окне и после очистки данных
сайта изменения не сохранятся.

## Возможности

- Списки, карточки, создание, редактирование, логическое и физическое удаление
  для всех пяти сущностей.
- Поиск, фильтры, сортировка, пагинация, выбор нескольких записей, адаптивная
  таблица и карточки.
- Проверки полей с сообщением под каждым полем, проверка уникальности
  регистрационного номера препарата и адреса почты поставщика.
- Связи: препарат → производитель, препарат ↔ категории, поставщик ↔ лицензия.
  После выбора производителя в форме препарата доступны только работающие
  с ним поставщики.
- Локальное сохранение JSON через `shared_preferences` в хранилище браузера.
  Изменения переживают обновление страницы и перезапуск браузера на том же
  устройстве и в том же профиле.

Данные не передаются на сервер и не синхронизируются между устройствами.
Начальные записи создаются из `lib/repositories/seed_data.dart` только при
первом запуске для данного адреса сайта.

Проверка проекта:

```shell
flutter analyze
flutter test
flutter build web
```
