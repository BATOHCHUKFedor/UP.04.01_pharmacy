# Аптечный каталог — Flutter Web + REST API

Пять разделов: препараты, поставщики, производители, категории и лицензии.
Текущий этап — ПР4: работа с сервером через Dio.

## Запуск

Нужны Flutter и Node.js 22+. У сервера нет npm-зависимостей.
Команды выполняются из корня проекта в двух терминалах.

Первый терминал:

```powershell
node mock-server.js --port 8080 --origin http://localhost:5555
```

Проверка: http://localhost:8080/api/__health — ответ `{"status":"ok"}`.

Второй терминал:

```powershell
flutter pub get
flutter run -d chrome --web-port=5555 --dart-define=API_BASE_URL=http://localhost:8080/api
```

`--origin` должен точно совпадать с адресом вкладки, включая порт.
`localhost` и `127.0.0.1` — разные источники. При смене API-адреса
перезапустите Flutter с новым `--dart-define`.

## Хранение

Источник данных — сервер. Начальный каталог: `server/seed-data.json`.
Каждое успешное изменение сохраняется в `.mock-data/catalog.v1.json`;
при следующем запуске сервер читает этот файл. Изменения переживают
обновление вкладки, перезапуск браузера и сервера. Физически удалённые
записи не возвращаются из начального набора.

Клиент держит текущую страницу каждого посещённого раздела, открытые
карточки и кэш справочников. Старые изменения из хранилища браузера ПР3
автоматически не переносятся. Локальный репозиторий сохранён для тестов
прежнего этапа, но в приложении подключён только API-репозиторий.

Для демонстрации без изменения основного каталога:

```powershell
node mock-server.js --port 8080 --origin http://localhost:5555 --data-file .mock-data/demo.json
```

`--no-persist` явно отключает сохранение: изменения живут до остановки
такого экземпляра сервера. Это не режим по умолчанию.

## Демонстрация ошибок

- 500: http://localhost:5555/drugs?__fail=500
- Задержка 1500 мс: http://localhost:5555/drugs?__delay=1500
- Недоступность: остановите сервер через Ctrl+C и обновите список;
  после запуска сервера нажмите «Повторить».
- 422: создайте препарат с существующим номером `ЛП-001201`, остальные
  поля заполните корректно.
- 409: в карточке препарата с нулевым остатком нажмите «Отпустить».
  В исходном каталоге это «Парацетамол», `/drugs/1`.

Диагностические параметры передаются API из URL. Уберите их из адреса
или нажмите «Сбросить» для обычного режима. HTTP 500 не повторяется
автоматически: повторы — только при сетевом сбое чтения, до трёх попыток.

## Проверка

```powershell
flutter analyze
flutter test
node --test server/mock-server.test.js
flutter build web --dart-define=API_BASE_URL=http://localhost:8080/api
node tool/verify_cors.js
node tool/verify_web.js
```

Браузерные проверки запускают headless Chrome/Edge во временном профиле.
`verify_web.js` требует свободных портов 5555/8080 и собранного приложения;
рабочее хранилище не меняет. Снимки: `build/verification`.
