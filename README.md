# Аптечный каталог

Учебный Flutter Web-проект с двумя сущностями: «Препарат» и «Поставщик».

Запуск:

```shell
flutter pub get
flutter run -d chrome
```

Реализованы слои `models`, `repositories`, `state`, `screens`, `widgets`, управление состоянием через `provider`, маршрутизация `go_router`, адаптивные списки, поиск, фильтры, сортировка, пагинация и два типа удаления.

Подробности выполнения и описание исправления `deleteMany` приведены в [REPORT.md](REPORT.md).
